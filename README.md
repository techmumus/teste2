# Prime Numbers Finder

This repository contains Python scripts to find and list all prime numbers from 1 to 1000.

## Files

1. **primes_1_to_1000.py** - Basic implementation using individual prime checking
2. **primes_optimized.py** - Optimized implementation using the Sieve of Eratosthenes algorithm
3. **primes_1_to_1000.txt** - Output file containing all primes from 1 to 1000 (generated by primes_1_to_1000.py)
